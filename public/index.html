agentcast

Watch a coding agent work. Live, from a link.

agentcast streams your Claude Code session to a shareable page: prompts, replies, tool calls, diffs and results, as they happen. When the session ends, the link becomes a replay.

1. Install the hookOne command, needs Node 18+. It downloads the hook to ~/.agentcast and adds it to your Claude Code settings.
curl -fsSL https://agentcast.agentcast.workers.dev/install.sh | sh
Only one project? Add -s -- --project ~/your-repo. Remove with -s -- --uninstall.
2. Start a sessionOpen Claude Code as usual. The share link appears as a system message on startup.
3. Share the linkAnyone with the link watches live, then scrubs through the replay once the session ends.
Live and replayEvents stream over WebSockets. Ended sessions get a timeline scrubber with play, step and speed controls.
Private linksSet AGENTCAST_PASSPHRASE and viewers must enter it before anything loads.
Smart titlesWhen a session ends, a model running on Cloudflare writes a title and two-line summary for link previews.
24-hour expirySessions delete themselves a day after they start. No accounts, nothing indexed.

Privacy defaults: the agent’s private thinking is never uploaded, common secret formats are redacted before leaving your machine and again on the server, and only your project folder name is sent, never the full path. AGENTCAST_DISABLE=1 pauses streaming, AGENTCAST_NO_AI=1 skips the generated summary.
